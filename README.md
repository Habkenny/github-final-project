# github-final-project

A simple, responsive Interest Calculator built with HTML, CSS, and JavaScript. The application allows users to enter a principal amount, interest rate, and time period to calculate the interest earned and the final amount.


📌 Features
Calculate simple interest instantly
Enter a custom principal amount
Enter an annual interest rate
Select the investment/loan period
Displays:
Interest amount
Total amount
Input validation
Responsive design for desktop, tablet, and mobile devices
Clean and simple user interface
No external libraries or frameworks required
🧮 Formula

The calculator uses the Simple Interest formula:

Simple Interest = (P × R × T) / 100

Where:

P = Principal amount
R = Annual interest rate (%)
T = Time period in years

The total amount is calculated as:

Total Amount = Principal + Simple Interest

Example

If you invest £1,000 at an annual interest rate of 5% for 2 years:

Interest = (1000 × 5 × 2) / 100
         = £100

Total Amount = £1,000 + £100
             = £1,100
